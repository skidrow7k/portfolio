# Portfólio — Skidrow

Portfólio responsivo em HTML, CSS e JavaScript puro, em português, com habilidades em Blender, design gráfico, game design e interfaces para Roblox.

## Executar

Abra `index.html` no navegador ou, nesta pasta, execute:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

Não precisa de instalação de dependências nem de build. As fontes do Google Fonts são opcionais; há fontes locais de fallback.

## Personalizar

- Edite os textos e as seções em `index.html`.
- Ajuste cores e layout em `style.css`.
- Os filtros e o menu mobile estão em `script.js`.
- As quatro imagens da galeria são composições ilustrativas em CSS, não projetos reais. Substitua por imagens e descrições dos seus trabalhos quando estiverem disponíveis.
- A seção final pode receber seus links de contato quando você quiser adicioná-los.
